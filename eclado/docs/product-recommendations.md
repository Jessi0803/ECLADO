# 搭配選購設定

入口：商品詳細頁最下方、建立訂單前的結帳訂單明細下方。付款單建立後不再顯示加購。

設定檔：`src/config/productRecommendations.js`。

- `CLEANSING_PRODUCTS`：四種清潔商品依操作順序排列，各自推薦其餘商品。
- `PROFESSIONAL_RECOMMENDATIONS`：以主商品固定 slug 為 key，陣列順序就是展示順序。金緞主商品為 `gold-patch`（金箔貼片）。
- 單個項目只有一個 `products` slug 時是一般搭配；多個 slug 時是同一步驟的替代商品，前台分別呈現商品，保留「擇一搭配」標示供使用者參考，不強制限制購買。
- 使用資料庫既有固定 slug，不用顯示名稱、價格或 SKU 比對。改名不影響推薦；變更 slug 時須同步修改設定並重新部署。
- 清潔商品不會自動插入院線推薦。院線內容依手冊流程頁設定；主套組內含兩劑、儀器、耗材及另頁延伸介紹不列入。

商品圖片、規格、會員價與現貨／預購狀態取用現有商品資料。草稿、封存、活動限定、贈品限定與不符合購買資格的商品不會出現在推薦中。零庫存沿用預購規則。設定中的商品不在目前目錄時，該項目自動隱藏；不會自動換成其他商品。

商品頁使用商城既有商品小卡，滑鼠移入顯示加入購物車，點擊圖片或名稱可前往詳細頁；加入後推薦仍保留，可重複加入。結帳合併各主商品的推薦並去除重複項目，已購商品及安瓶替代款仍然顯示。結帳區每列 84px，最多顯示約 3.5 列，其餘以內部捲動瀏覽；以右側「＋」每次加入 1 件，可切換容量。商品頁小卡加入預設容量，其他容量可至商品詳細頁選擇。不會跟隨主商品數量增加，單規格數量上限為 99。它們在購物車儲存 `recommendationOnly` 旗標，重新整理後仍不會成為下一輪推薦的來源；這個旗標不參與價格或權限判斷。

加購修改既有購物車，重新取得後端報價並沿用優惠券失效重套、促銷、運費與錢包規則。優惠碼驗證及訂單送出期間暫停加購。沒有另外設定加購折扣，也沒有後台或資料庫異動。
