# 全站公告

活動管理新增「全站公告」分頁，沿用既有後台字體、顏色、邊框與按鈕；提供顯示開關、最多 200 字公告、字數統計及即時跑馬燈預覽。儲存失敗保留編輯內容。

前台將公告置於主導覽列下方（36px），首頁透明導覽列時採透明底白字，捲動後與其他頁面同步採淺底深字；手機選單下移至公告下方。登入等既有無導覽列的頁面將公告放於頁面頂端。關閉、空白或讀取失敗時不保留空白列。文字依使用者減少動態偏好改為靜態顯示；一般模式滑鼠停留可暫停。

公告為獨立的公開文案，不自動建立優惠，不修改現有活動與運費規則。公告會以 Realtime 接收儲存變更，視窗重新取得焦點時也會重新讀取。既有商城自動優惠提示保留。

## 安裝
