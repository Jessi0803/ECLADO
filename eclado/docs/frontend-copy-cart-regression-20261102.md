# 前台文案、購物車與回歸修正（2026-11-02）

## 修改範圍

- 優化登入、密碼、聯絡、商城、購物車、結帳及付款結果的顧客提示；減少工程細節，保留付款期限與避免重複付款等必要指引。
- 首頁第一、第三張輪播統一使用「瀏覽保養商品」，皆前往商城。
- 異常舊式折扣活動不顯示優惠說明與標籤，正常折扣及贈品活動維持顯示。
- 修正會員角色查詢未完成就校驗購物車的競態，避免內部人員重新載入時誤刪院線商品。
- 舊訂單折抵明細的備援名稱補回優惠券名稱與遮罩代碼，兼容原始與正規化欄位；有效快照明細仍優先保留。
- 修正測試定位、後台捲動前置條件、診斷空紀錄文案預期及業績測試模組匯入。
- 美容師申請測試先驗證重複申請阻擋提示，再由明確按鈕進入會員專區，避免依賴角色載入期間的暫時跳轉。

## 購物車根因與修正

原本 session 就緒後會立即設為 authReady，但 profiles 查詢仍可能進行中。商品載入先完成時，購物車校驗把 user 尚未就緒視為無院線購買資格，移除商品並將空購物車存回 localStorage。

修正後，會員角色查詢完成前維持未就緒狀態；既有查詢序號仍防止過期回應覆蓋目前會員。沒有在 Supabase 認證事件回呼中新增等待 profile 查詢，避免改變其鎖定時序。

新增以 Promise gate 延遲角色查詢的回歸案例。修正前可穩定重現商品消失；修正後，等待期間保留商品，確認為 staff 後保留且可結帳，確認為 consumer 後仍移除沒有資格購買的院線商品。

## 規則維持不變

未修改付款 API、付款通知、付款核對、資料庫／SQL、折扣計算、購買資格、最低訂購額、免運門檻及錢包最低外部付款額規則。優惠券修正僅影響名稱顯示。
