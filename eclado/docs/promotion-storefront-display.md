# 指定商品活動顯示

後台保留活動名稱與顧客說明，新增選填的活動標籤（最多 20 字）、色塊選色與即時預覽。標籤留空時小卡不顯示標籤，商品詳情仍顯示活動名稱及顧客說明（保留換行）。同一商品可同時顯示多個活動。

只顯示有效期間內、未封存且啟用、符合目前訪客／會員適用對象的指定商品自動活動。全館活動及優惠券專用活動暫不顯示；標籤不代表已達滿額／滿件門檻，結帳仍以既有計價系統判定。折扣、贈品與付款規則沒有改動。

## 部署順序

1. 在既有活動引擎與 `supabase-automatic-promotion-audience.sql` 之後執行 `supabase-promotion-storefront-display.sql`。此腳本新增顯示欄位、回填既有活動範圍，並包裝目前已安裝的儲存 RPC。舊客戶端省略標籤欄位時保留原值。未擴大 RLS 或公開內部儲存函式。
2. 部署前後台。編輯一筆指定商品自動活動，填寫標籤、選色與顧客說明，儲存後重新開啟確認保留，再確認商城小卡與詳情。
3. 確認全館活動即使保留 product_ids，也不會出現指定商品標籤。

如日後重建活動儲存 RPC，需在所有引擎腳本之後重跑本腳本，保留新增顯示欄位的儲存行為。範圍以現有管理介面的儲存 RPC 同步；不應直接手動修改 promotion_scopes 而略過 RPC。
