# 結帳失敗與重試：本地模擬證據

本目錄為 2026-10-23 的本地模擬，不是正式付款紀錄。`result.json` 記錄 `simulation=true`、`realApiTraffic=false`；訂單編號為 ECL-E2E 模擬值，畫面收件人「本地流程測試」與電話 0912345678 為測試資料。沒有真實客戶下單或銀行交易。

- `01-processing.png`：建立付款單期間顯示處理中按鈕。
- `02-failed-button-restored.png`：失敗提示後，建立付款單按鈕恢復可操作。
- `result.json`：模擬程序記錄兩次付款請求、兩個不同模擬訂單編號，以及失敗後按鈕可用。

原第 3 張重試截圖與第 2 張的 SHA256 完全一致，因此不作為額外證據提交。重試次數與模擬訂單結果只由 JSON 紀錄支持，不宣稱截圖能證明新訂單建立，也不視為正式金流端到端驗收。
