# 課程付款期限與保留報名：正式發布紀錄

本次僅整合 `codex/course-payment-resume` 的課程付款期限、原單續付、未付款提醒、保留報名及歷史逾期恢復。原工作目錄其他修改不納入。

## 行為

- 付費報名送出即受理；付款期限至課程開始前。四種付款方式沿用原訂單續付，銀行查證先於續付。
- 開課仍未付款時顯示「已報名／付款已逾期」，不自動取消；由後台依客人要求取消。已付款／免費報名的上課與購物金條件沿用原規則。
- 一般已建立付款資料的訂單不提供任意切換方式。只有銀行確認逾期未付款、符合資格的歷史自動取消單，由服務端執行一次恢復，才能重新選擇方式。
- 未付款提醒採報名後 24 小時與開課前 24 小時；接近開課時合併或調整時間，最短間隔與送前查證依 SQL 實作，逾期停止提醒並保留報名。
