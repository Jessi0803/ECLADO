# 購物車：活動達標但折後未滿低消的提示

程式與配套增量 SQL 已完成；正式配套 SQL 已安裝並驗證，前端隨本次提交發布。正式規則仍為折後商品金額滿5,000元（不含運費），既有追加訂單例外保留。

## 行為

買五送一的六罐呼吸安瓶，學生9折小計5,022，活動折抵930，活動組學生折扣加回558，淨折抵372，折後商品金額4,650。購物車與側邊購物車將清楚顯示：

- 已達活動優惠條件。
- 優惠後商品金額：NT$ 4,650（不含運費）。
- 最低訂購金額NT$ 5,000，還差NT$ 350。
- 請再加入商品，折後滿NT$ 5,000即可結帳。

同時保留兩筆帶正負號的活動價格明細。沒有實際套用活動時不顯示「已達活動優惠條件」。第7罐保留學生價，折後5,487，重新取得正常報價後清除不足提示並恢復結帳。數量變更時不沿用舊預覽；不完整或無法解析的低消拒絕仍阻擋結帳。

## 後端契約

`supabase-cart-minimum-preview.sql` 只在既有低消例外增加 DETAIL JSON，保留相同22023錯誤、相同低消條件及追加訂單例外。預覽不含成功報價的total、訂單快照或可用於建單的確認資料，仍無法建立未滿低消的訂單。

只回傳小計、淨折扣、商品金額、低消、差額，以及白名單活動名稱／金額／類型。不傳商品成本、師生綁定或其他私有快照。前台另外解析為顯示用途，沒有改動共用結帳報價或建單服務。既有owner／ACL在安裝交易內檢查保持一致。
